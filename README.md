# B站空间页增强工具（userscripts）

按阶段交付的 Tampermonkey 脚本，用来改进 B 站用户空间页：

| 阶段 | 脚本 | 页面 | 功能 | 状态 |
|---|---|---|---|---|
| 1 | `dist/01-动态翻页.user.js` | `/uid/dynamic` | 动态翻页，每页 12 条 | ✅ 已交付 v0.2.1，待实测 |
| 2 | `dist/02-图文翻页.user.js` | `/uid/upload/opus` | 图文翻页，每页 20 条 | ✅ 已交付 v0.2.0，待实测 |
| 3 | `dist/03-图文统一行高.user.js` | `/uid/upload/opus` | 同一行卡片等高（该行最高为准） | 待实现 |
| 4 | `dist/04-图文排序.user.js` | `/uid/upload/opus` | 左→右、上→下 按日期从新到旧 | 待实现 |
| 5 | 待定 | — | 翻译按钮（B 站原生按钮样式） | 需求待确认 |

## 安装（Tampermonkey）

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展。
2. 打开 Tampermonkey 管理面板 → **实用工具** → **导入文件**，选择 `dist/` 下对应的 `.user.js`；
   或者直接把 `.user.js` 拖进浏览器窗口，按提示安装。
3. 打开 B 站空间页：
   - 动态：`https://space.bilibili.com/<uid>/dynamic`
   - 图文：`https://space.bilibili.com/<uid>/upload/opus`

> 两个脚本作用于不同页面，可以同时启用。阶段 3/4 会覆盖安装图文脚本，届时禁用上一版图文脚本即可。

## 阶段 1 已实现（动态，v0.2.0）

- 动态页每页只显示 **12 条**，与 B 站自动加载的条数一致；其余已加载条目隐藏。
- **保留 B 站原生的“滚到底自动加载”**：滚到当前页底部时，B 站会预取正好下一页的 12 条，
  新条目会立即隐藏，所以看不到闪动、分页条也不会被顶下去；点“下一页”时通常已经加载好、即时打开。
- 分页条 1:1 复刻 B 站原生 `VPagenation` 的 DOM/class/尺寸，跟随亮色/暗色主题。
- 支持上一页 / 下一页 / 页码 / 输入跳页；总页数未知前显示“第 X 页 · 已加载 N 个”，到末页后显示总页数。
- 原生加载条在分页模式下隐藏；切换 全部/视频 tab、刷新、SPA 切 UP 主都会回到第 1 页。
- 若取不到列表实例，自动退化为纯 DOM 模式。

## 阶段 2 已实现（图文，v0.2.0）

- 图文页每页只显示 **20 条**（实测 B 站图文每次自动加载 20 条），其余已加载条目隐藏。
- **保留 B 站原生的“滚到底自动加载”**：滚到当前页底部会预取下一页 20 条；新条目不进当前页，
  分页条位置不跳动，点“下一页”通常即时打开。
- 复用 B 站原生卡片样式（`.opus-card` / `.bili-cover-card` / 原生图标），用原生 class 重建卡片：
  封面比例、2 行标题、点赞/浏览统计、充电徽章、作者·时间副标题、纯文字卡片。
- 封面使用 B 站图床缩略图（`@640w.webp`，约 25KB/张），并预热下两页封面；翻页基本看不到灰色占位。
- **图片压缩开关**（Tampermonkey 扩展菜单里的“图片压缩：开/关”，默认开启，`localStorage` 持久化）：
  - 开启：加载压缩后的封面（`@640w.webp`，快、省流量）；
  - 关闭：加载原图（画质最好，20 张约 6.8MB）；
  - 点击菜单立即重绘当前页；关闭时不预热后续页面。
  - 实现上菜单命令需要 `GM_registerMenuCommand`，脚本用 `@sandbox raw` 保持页面上下文（继续读 Vue 实例/拦截接口）。
- 布局复刻原生 `WaterfallGrid`：前 10 条行优先、之后最短列，列宽/列数与原生公式一致；窗口缩放自动重排。
- 数据通道：
  1. 优先读页面自身 Vue 实例的 `WaterfallGrid`（`props.list` / `onLoadMore`）；
  2. 拿不到实例时退化为接口抓包（`/x/polymer/web-dynamic/v1/opus/feed/space`），只读不改响应。
- 分页条复用共享的原生 `VPagenation` 组件；切换 全部图文/专栏/动态 tab 自动回第 1 页。
- 两通道都拿不到数据时完全不接管，原生页面保持可用。

## 开发

```powershell
npm install
npm test               # 单元测试（分页窗口、图文布局/高度/列宽）
npm run test:e2e       # 动态假页 e2e
npm run test:e2e:opus  # 图文假页 e2e（含 Vue 通道与抓包通道）
npm run test:live:opus # 图文真实站点冒烟（可选，需要联网）
npm run test:e2e:real  # 真实页面 DOM 快照测试（动态）
npm run test:visual    # 分页控件与原生参考的尺寸/视觉对比
npm run build          # 生成 dist/*.user.js
```

- 源码在 `src/`：`shared/` 是两边共用的已验证部件（分页条、DOM、日志、样式、toast），
  `scripts/` 是两个入口，`opus/` 是图文专属的数据/布局/卡片模块。
- `参考文件/` 是本地保存的 B 站页面快照（只读资料，约 50MB），已在 `.gitignore` 中排除。
- 文档：[计划](docs/PLAN.md) · [调研](docs/RESEARCH.md) · [任务清单](docs/TASKS.md) · [测试说明](docs/TESTING.md)

## 已知限制

- 需要登录态的真实页面无法在本机自动化测试，脚本行为以假页测试 + 用户实测为准。
- 跳页是本地分页：要跳很远会顺序加载中间所有页（脚本会提示请求次数）。
- 分页模式下的“滚到底自动加载”是刻意的下一页预取：滚到当前页底部会先预取下一页（“已加载 N 个”会增加），
  但当前页只显示每页条数，点“下一页”即可查看。
- 图文页的列数/列宽跟随 B 站公式；窗口特别窄或页面结构变化时若出现异常，脚本会在控制台输出原因并停止接管。
