统一行高：按“平均值”裁剪示意图

示意图中的高度单位为 px；卡片高度 = 封面 + 标题/正文。行高裁剪是裁掉卡片底部超过平均值的部分（高竖图会被裁，普通卡片保留）。
① 平均值 = 0：不裁剪，行高 = 该行最高卡片，显示原始内容。
② 行内最高 − 最低 ≤ 差距阈值（示意用 40px）：视为“差距不大”，行高 = 最高卡片，显示原始内容。
③ 最高卡片 ≤ 平均值 + 差距阈值：峰值只略高于平均值，也保留原始内容。
④ 否则：行高 = 平均值；只裁掉卡片底部超过平均值的部分，低于平均值的卡片保持原始内容。
卡片原始内容 超过平均值、被裁剪 差距不大：保留原始 平均值线

三、超过平均值的高度速查表（px）

行 = 卡片自然高度；列 = 平均值；单元格 = 会被裁掉的高度。0 表示不裁剪；数字越大裁得越多。
说明：表格按“大差距行”计算裁剪量 = max(0, 卡片高度 − 平均值)；小差距行会按规则②整体保留，不裁剪。
实测参考：B 站图文卡片自然高度约 150–650px，整行高度常见 260–576px；平均值 320–420 可以压掉特别高的竖图，同时让普通行尽量保持原始。
建议先试：平均值 360px（比较稳）；想保留更多高图就调大（400 / 440 / 480），想压得更狠就调小（300 / 280 / 0 不裁剪）。
差距阈值暂定 40px（可再调）；如果你希望“差距不大”的判定更宽松/更严格，也请一起告诉我。
