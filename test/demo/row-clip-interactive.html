统一行高：裁剪阈值互动演示

每行自动计算卡片自然高度的平均值 A；可调的是“最高卡片超出平均值的比例”。 输入或拖动阈值，下面会实时显示哪些行会被裁剪、裁到什么高度。 阈值 = 0 表示停用（不裁剪）。

裁剪阈值（%）

30%
规则：超出比例 = (最高 − 平均) ÷ 平均；超出比例 > 阈值 → 裁剪，行高 = 平均值；≤ 阈值 → 原始内容，行高 = 最高值。0 = 停用。
说明：实际脚本对超过平均值的卡片使用 B 站原生封面比例 + object-fit: cover 裁剪（标题保留）；本页的红色斜纹只表示“超过平均值”的部分，方便理解阈值。
① 行平均值 A = 该行所有卡片自然高度的平均（自动计算）。
② 超出比例 = (最高 M − A) ÷ A × 100%。
③ 超出比例 ≤ 阈值：差距不大，行高 = M，原始内容。
④ 超出比例 > 阈值：行高 = A，只裁掉高于 A 的底部。
⑤ 阈值 = 0：停用，不做任何裁剪。
低于 A 的卡片保留原始内容，行高为 A 时下方留白，不再强行展开文字。
卡片原始内容 高于平均值被裁剪 平均值线 A 最终行高
